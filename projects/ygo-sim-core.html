Haunted Labs Compute Engine · SPEC-SIM-2026-001

ygo-sim-core

Autonomous, high-performance deterministic simulation and state-space valuation engine ("Stockfish for Yu-Gi-Oh!"), exposing Model Context Protocol (MCP) tooling to LLM reasoning agents.

View on GitHub Architectural Blueprint →

The Stockfish Paradigm for Trading Card Games

Competitive TCG play involves combinatorially explosive decision trees, complex timing structures, and multi-tier chain interactions. Traditional heuristics and static deck builders cannot simulate the consequences of opponent interruptions or calculate the optimal branch out of hundreds of legal moves.

ygo-sim-core decouples heavy mathematical simulation from natural language AI reasoning. Acting as a dedicated compute engine (analogous to Stockfish in chess), it exposes strict JSON-RPC tools via the Model Context Protocol (MCP) to autonomous LLM agents (such as obsidian-ygo-suite).

Architectural Boundary
ygo-sim-core (Pure Compute): 14-zone state memory, Fast Effect state machine, combinatorial graph search, xxHash64 transposition tables, and Monte Carlo tests.
Agent Reasoning Layer: Tactical coaching, deckbuilding advice, rule dispute adjudication, and natural language explanations.

Key Systems Engineering Innovations

1. 14-Zone Full Memory State Model

Models all physical zones with strict structural immutability: Main Monster Zones (M1..M5), Spell & Trap Zones (S1..S5), Extra Monster Zones (EL, ER), Field Zone, Graveyard, Banished, Hand, Main Deck, and Extra Deck.

2. Official Fast Effect Timing State Machine

Faithfully codifies the Konami priority flowchart across Boxes A, B, C, D, and E. Handles turn player priority passes, open game state transitions, and Spell Speed 1, 2, and 3 reaction timings.

3. SEGOC & Chain Blocking Engine

Implements Simultaneous Effects Going On Chain across all 4 official tiers (Turn Player Mandatory → Opponent Mandatory → Turn Player Optional → Opponent Optional). Detects optimal chain order to block opponents from responding to high-value effects with direct negations.

4. Zero-Collision 64-bit State Hasher

Integrates xxHash64 with canonical permutation sorting of unordered zones (e.g., Hand, GY). Eliminates cyclic loop traversal during DFS search and enables instantaneous transposition table lookups.

5. Multi-Layer Board Valuation Engine — V(YBN)

Mathematical valuation of end-boards scoring:

  • Spatial Diversification: Interaction distribution across monster, backrow, and graveyard zones.
  • Board Breaker Resilience: Defense against board sweeps like Dark Ruler No More, Evenly Matched, and Super Polymerization.
  • Turn 3 Follow-up Recursion: Guaranteed card advantage generated during recovery turns.

Model Context Protocol (MCP) Tool Contract

When started as a stdio server, ygo-sim-core registers four production tools directly with AI agents:

MCP Stdio Tools JSON-RPC / Zod Schemas 
1. simulate_test_hands
   Inputs: deck_path (.ydk), iterations (default: 1,000), target_combos
   Outputs: Full consistency metrics, brick percentages, starter distributions

2. explore_combo_tree
   Inputs: starting_hand, max_depth, branch_limit
   Outputs: Combinatorial tree of legal playlines, ranked by V(YBN) end-board score

3. evaluate_handtrap_resilience
   Inputs: combo_line, interruptions: ["Ash Blossom", "Nibiru", "Impermanence"]
   Outputs: Choke-point sensitivity report, recovery paths, degraded end-boards

4. score_ybn_state
   Inputs: ybn_string (snapshot descriptor)
   Outputs: Multi-layer V(YBN) score vector across omni-negates, removal, and follow-up
